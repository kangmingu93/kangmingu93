# 강민구 | minggle

두꺼비세상에서 **피터팬의 좋은방 구하기** Android 앱을 개발하고 운영합니다. Kotlin과 Jetpack Compose를 사용해 기능을 개발하고, 기존 앱 구조를 단계적으로 개선하며 정기 배포와 장애 대응을 맡아 왔습니다.

[경력과 개발 사례](https://career-lyart-nine.vercel.app/)

## 운영 중인 서비스

- [모바일 청첩장](https://wedding.jiguworks.com/w/sample) — 모바일 웹 청첩장입니다. 가상 정보로 구성한 공개 샘플에서 화면과 흐름을 확인할 수 있습니다.
- [한푼두푼](https://hanpundupun.jiguworks.com) — 수입·지출과 일정을 한곳에서 관리하는 가계부입니다. 직접 사용하며 개선하고 있습니다.
- [포춘크루](https://fortune.jiguworks.com) — 사주·타로·별자리·성향을 바탕으로 한 자기 탐색 서비스입니다. 전통적 해석을 제공하며 미래 예측이나 진단을 보장하지 않습니다.

## 개발 중인 프로젝트

- **TripSheet** — Kotlin Multiplatform과 Compose Multiplatform으로 만드는 여행 일정·진행·기록 플래너
- **planforge** — PRD, 기능 명세, 유저 플로우를 연결하는 로컬 AI 기획 도구
- **모아이브**, **foreshadow** — 개발 중인 앱 서비스
