# 강민구 | minggle

두꺼비세상에서 ‘피터팬의 좋은방 구하기’ Android 앱을 개발합니다.  
주로 **Kotlin과 Jetpack Compose**를 사용합니다.

개인 프로젝트에서는 **Codex와 Claude Code**를 활용해 앱과 웹 서비스를 만듭니다.  
모바일 청첩장과 개인용 가계부 한푼두푼을 운영하고 있습니다.

현재는 포춘크루, 여행 플래너 트립시트와 여러 앱 서비스를 개발하고 있습니다.

## 운영 중인 서비스

### [모바일 청첩장](https://wedding.jiguworks.com/w/sample)

결혼 소식을 전하는 모바일 웹 청첩장.  
완성된 서비스의 화면과 흐름을 가상 정보로 구성한 샘플로 공개합니다.

### [한푼두푼](https://hanpundupun.jiguworks.com)

수입·지출과 일정을 한곳에서 관리하는 개인용 가계부.  
직접 사용하기 위해 만들었으며, 현재 운영 중입니다.

### [포춘크루](https://fortune.jiguworks.com)

사주·타로·별자리·성향을 통해 나를 탐색하는 웹 서비스.  
현재 운영하며 기능과 사용자 흐름을 개선하고 있습니다.

전통적 해석과 자기 탐색을 위한 콘텐츠로, 미래 예측이나 진단을 보장하지 않습니다.

## 만들고 있는 프로젝트

- **TripSheet**: 계획형 여행자를 위한 여행 일정·진행·기록 플래너. Kotlin Multiplatform·Compose Multiplatform 기반으로 개발 중입니다.
- **planforge**: PRD, 기능명세서, 유저플로우를 연결하는 로컬 AI 기획 도구. Claude Code와 Codex CLI를 활용합니다.
- **모아이브**: 개발 중인 앱 서비스.
- **foreshadow**: 개발 중인 앱 서비스.

서비스 소스는 비공개로 관리하며, 공개 가능한 화면과 개발 과정을 소개합니다.
